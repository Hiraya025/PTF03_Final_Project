Naming convention for adding models (Add to /model folder):
- best_model.pkl - the best-performing trained model
- scaler.pkl - the StandardScaler or MinMaxScaler used during training (critical — inputs must be scaled the same way)

Run on VSCode terminal:
python -m pip install -r requirements.txt

To run app in terminal:
python app.py

To run app in onrender:
https://ptf03-final-project.onrender.com/
